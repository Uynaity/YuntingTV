# 睡眠定时交互重做：手机底部弹窗、电视上下键+环形倒计时

## Goal

去掉睡眠定时现有的居中弹窗（`SleepTimerOverlay` + `SleepTimerSlider`），
手机端改为从屏幕底部弹出的菜单（同节目单风格），电视端改为聚焦按钮后上下键就地调节 + 环形倒计时。

## Requirements

### 手机端（horizontal 布局）
- 睡眠定时不再用居中 `Dialog` 弹窗，改为从屏幕下方滑入的底部菜单，与节目单 `PlaybillBottomSheet` 同一交互风格（滑入/滑出动画、遮罩、点遮罩/返回键关闭）。
- 高度不固定 50%，改为「按内容自适应」——只需完整容纳标题 + 可拖动的进度条（滑块）即可。
- 滑块交互沿用现有 `SleepTimerSlider`：0..120 分钟，步长 15，0=关闭；触屏拖动松手提交。

### 电视端（vertical 布局）
- 去掉弹窗与滑块。
- 光标聚焦睡眠定时按钮后：
  - 按「上」键 +15 分钟，按「下」键 -15 分钟；范围 0（关闭）..120 分钟。
  - 上下键调节时按钮显示「待定值」（未提交）。
  - 焦点离开按钮且未按确认 → 待定值还原为当前已生效值（丢弃未确认修改）。
  - 按「确认」（DPAD_CENTER/Enter）→ 提交待定值并开始倒计时。
- 倒计时进行中：按钮外围显示一圈圆形进度条环绕按钮，随剩余时间收缩。

## Acceptance Criteria

- [ ] 手机端点睡眠定时按钮从底部弹出菜单，高度仅够标题+滑块，非 50%。
- [ ] 手机端滑块拖动可设置 0..120（步长 15），松手生效，弹窗滑出关闭。
- [ ] 电视端聚焦按钮后上下键调节待定值并在按钮上显示，上下键不导致焦点移走。
- [ ] 电视端焦点移开未确认时待定值还原为已生效值。
- [ ] 电视端按确认后生效并开始倒计时，按钮外围出现环形倒计时进度条。
- [ ] 直播/回放两种播放态下均正常，未播放（channel 为空）时按钮禁用行为不变。

## Notes
- 现有实现集中在 `PlayerPanel.kt` 的 `SleepTimerButton` / `SleepTimerOverlay` / `SleepTimerSlider`。
- VM 侧 `sleepTimerRemainingMinutes` / `setSleepTimer(Int)` 契约保持不变。
