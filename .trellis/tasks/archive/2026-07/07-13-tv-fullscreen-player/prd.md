# TV 全屏播放界面

## Goal

在 TV 端提供一个优雅的全屏播放界面：用户把光标移到左侧 `PlayerPanel` 的电台 LOGO 上按确认即展开；渐隐渐现进/出；参考 Apple Music 全屏播放器（大封面居中、电台名、节目名、进度条、播放键），右上角显示当前时间；背景用 LOGO 取色 + 高斯模糊，保证黑底/白底 LOGO 下文字都清晰；返回键退出。

## Requirements

- 入口：横屏左侧 `PlayerPanel`（`horizontal=false`）的封面可聚焦，按确认键展开全屏；无当前电台时不可展开。
- 进入/退出动画：渐隐渐现（fade），进出对称，tween ~300ms，流畅无跳变。
- 退出：返回键关闭全屏，回到原界面（优先级高于 playbill / 筛选栏收起 / 退出对话框）。
- 全屏布局：居中大号圆角 LOGO；下方电台名（标题）、节目名（副标题）、进度条、播放/暂停键；右上角当前时间（24h）。
- 背景：Coil 加载 LOGO 缩略位图 → androidx.palette 取主色（darkVibrant → vibrant → dominant）作底色；API 31+ 叠放大模糊的 LOGO 图；统一暗色渐变 scrim 保证白字在黑/白 LOGO 下均清晰。
- 播放交互复用现有能力：进度条可聚焦、左右键 ±15s/长按步进（回放）；直播只读；播放键切换播放/暂停。
- 兼容：minSdk 24。API<31 无高斯模糊时优雅降级为纯取色渐变 + scrim，不得崩溃或文字不可读。

## Acceptance Criteria

- [ ] 焦点在左侧 LOGO 上按确认 → 全屏以渐隐方式出现；无电台时按确认不展开。
- [ ] 返回键 → 全屏反向淡出，回到列表/播放面板；不误触发退出应用对话框。
- [ ] 白底 LOGO 与黑底 LOGO 两种电台下，标题/节目名/时间/进度均清晰可读。
- [ ] 全屏内进度条对回放可 ±15s seek，直播只读；播放键可切换播放/暂停。
- [ ] 右上角时间随分钟刷新；退到后台不空转。
- [ ] API 31+ 背景有高斯模糊；API<31 显示取色渐变背景，无崩溃。
- [ ] 编译通过（`./gradlew :app:assembleDebug`）。

## Notes

- 竖屏（手机）形态本次不改，全屏入口仅横屏 TV 左侧面板。
- 取色方案已定：androidx.palette-ktx（用户拍板）。
