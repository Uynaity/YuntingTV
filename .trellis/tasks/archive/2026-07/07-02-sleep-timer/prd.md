# 睡眠定时暂停播放

## Goal

为 App 增加"睡眠定时"：用户设定一个时长，到点后自动暂停播放。入口在播放器面板暂停按钮左侧，遥控与触摸两种交互均可操作，并实时展示剩余分钟。

## Requirements

- 入口：`PlayerPanel` 暂停/播放按钮**左侧**新增一枚定时按钮，横排（底部）与竖排（左侧 1/3）两种布局均需放置。
- 交互：点击定时按钮就地弹出**滑块**（值域 0–120 分钟，步长 15，0=关闭）。
  - 触屏：左右拖动滑块调值，松手即开始计时。
  - 遥控：滑块获焦后左右键调值，静止 1 秒即开始计时；返回键收起。
  - 两路共用同一值，仅提交触发不同（松手 / 1 秒防抖）。
- 计时：选定档位后开始倒计时，到点调用现有暂停路径（`controller().pause()`），只暂停不停止，`currentChannel` 保留可再播。
- 改档/关闭：重新选择即取消旧计时按新档位重开；选"关闭"则取消计时。
- 实时倒计时：定时进行中，按钮上（或其旁）实时显示剩余分钟，每分钟刷新；未设定时按钮为普通图标态。
- 无副作用重置：切电台 / 切来源 **不**重置计时器（"多久后睡"与放什么无关）。
- 计时进行中暂停/恢复播放不影响计时；到点若已是暂停态则幂等（再 pause 无害）。

## Acceptance Criteria

- [ ] 播放器面板暂停按钮左侧出现定时按钮，横排与竖排布局均正确显示。
- [ ] 点击定时按钮就地弹出滑块，值域 0–120、步长 15。
- [ ] 触屏：拖动滑块到 30 分钟松手，立即开始计时。
- [ ] 遥控：滑块获焦后左右键调值，静止约 1 秒后开始计时；返回键收起。
- [ ] 计时开始后按钮显示剩余分钟并逐分钟递减；到 0 时播放自动暂停。
- [ ] 滑块拖到 0（关闭）提交后计时取消，按钮回到普通图标态。
- [ ] 计时中切换电台/来源，计时不被重置。

## Notes

- 计时器实现放 `RadioViewModel` 的可取消协程，非 Service/AlarmManager（TV 常插电常亮，进程稳定，YAGNI）。
- 状态经 `RadioUiState` 透出：`sleepTimerRemainingMinutes`（0 = 未设定）驱动 UI。
