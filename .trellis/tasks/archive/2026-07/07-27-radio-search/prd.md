# 电台搜索功能（TV 左侧搜索键盘 + 网关搜索接口）

## Goal

在当前「地区 + 分类」筛选范围内按名称快速找台。TV/横屏用 D-pad 可操作的自绘方形键盘，
输入即搜、右侧列表实时出结果；中文台支持拼音首字母命中。

## Scope

- APP：搜索入口按钮、横屏左栏搜索界面（搜索栏 + 6 列方键键盘）、竖屏系统输入法、结果实时展示。
- 网关（radio-proxy）：新增 `/v1/search`，在指定 source + 地区 + 分类范围内做名称/拼音匹配。

## Requirements

### 入口与布局

1. 左上角「★ 收藏」右侧新增搜索按钮，与收藏 chip 同视觉规格（复用 `focusableChrome`）。
2. 横屏/TV：进入搜索后，左栏（0.32 权重，原 `PlayerPanel` 位置）整体换成搜索界面：
   上方搜索栏（回显已输入内容 + 光标），下方方形键盘。播放不中断（播放器在 Service 中）。
3. 竖屏（手机）：不显示自绘键盘；点搜索按钮后顶栏原位切换为 Material 3 搜索栏并唤起
   系统输入法，结果在下方实时展示且可直接触摸选择。状态栏/刘海/底部手势区必须按
   edge-to-edge + safe drawing insets 正确避让，TV 端继续保持沉浸式。
4. 地区/分类筛选栏在搜索态保持可见可用：改筛选即按新范围重新搜索。

### 键盘

5. 6 列方键，两态列数一致（切换时焦点不跳位）：
   - 字母态 5 行：`A-X` 四行 + 第 5 行 `Y Z 123 ⌫`
   - 数字态 2 行满格：`1-6` / `7 8 9 0 ABC ⌫`
6. `123` / `ABC` 为态切换键，`⌫` 为删除一个字符，二者嵌在键盘网格内，不额外占行。
7. 键位可 D-pad 上下左右移动、OK 键输入；边缘不吞焦点（右边缘可移到右侧列表/筛选栏）。

### 搜索行为

8. 每次输入/删除后等待 1 秒（防抖）自动发起搜索；期间继续输入则重新计时，只有最后一次生效。
9. 结果替换右侧电台列表；空查询时回到当前筛选的普通列表。
10. 搜索范围 = 当前来源 + 当前选中地区 + 当前选中分类。
11. 在「★ 收藏」视图下按搜索键：退出收藏视图，按当前地区 + 分类搜索。
12. 中文台默认按拼音首字母命中（如 `bj` → 北京文艺广播）；同时支持中文原文子串与全拼子串；
    英文台（TuneIn）按名称子串（不区分大小写）。
13. 结果为空时右侧显示「未找到相关电台」。
14. 结果列表支持翻页续取（沿用现有滚到底预取机制）。

### 退出

15. 返回键退出搜索：关闭搜索界面、左栏恢复播放器，右侧恢复进入搜索前的筛选列表（不重新请求）。
16. 在搜索结果里选台会正常播放并记入「上次播放」；搜索界面保持打开（按返回键回到播放器）。

## Constraints

- 服务端保持既有契约风格：`ApiResponse{code,message,data}`、`code==0` 成功、复用 `paginate`。
- 客户端只认网关这一套契约，不在 Kotlin 侧另写一份拼音匹配。
- 拼音转换在服务端完成；新增依赖需固定版本。
- 打字过程中不得对上游（云听/蜻蜓/TuneIn）产生每字符一次的回源请求。

## Acceptance Criteria

- [ ] TV 横屏：点搜索按钮 → 左栏变为搜索栏 + 6 列键盘，焦点落在键盘首键。
- [ ] 输入 `bj`（停手 1 秒）→ 右侧出现名称含「北京」的电台；期间快速连打不产生多次请求。
- [ ] 竖屏系统输入法输入中文「北京」→ 同样命中。
- [ ] 竖屏状态栏可见且不遮挡顶栏；刘海/挖孔与底部手势条不覆盖可交互内容。
- [ ] TuneIn 源输入 `bbc` → 命中 BBC 系列电台。
- [ ] `123` 切数字态、`ABC` 切回、`⌫` 逐字删除，切换后焦点仍在键盘内。
- [ ] 清空输入 → 右侧回到当前筛选的普通列表。
- [ ] 收藏视图下按搜索键 → 退出收藏并进入搜索态。
- [ ] 返回键退出 → 左栏恢复播放器，右侧列表与滚动位置为进入搜索前的状态。
- [ ] 搜索结果无匹配时显示「未找到相关电台」。
- [ ] 服务端 `go test ./...` 通过，含拼音首字母 / 中文子串 / 英文子串 / 空查询用例。
- [ ] 连续 10 次不同查询词，同一（source, 地区, 分类）范围内对上游只回源一次。
