# 播放器进度条（TV+手机，回放拖动/直播只读）

## Goal

在播放器面板加进度条：回放内容支持遥控器/触摸拖动定位，直播内容只读显示当前节目进度。TV 与手机两套视图，配色沿用播放键红色主题（YtmRed `#FF0033`）。

## 关键事实（已验证真实接口）

- 直播当前节目起止时间**两个源都能拿到**：
  - 蜻蜓 `GET v4/channels/{id}` → `nowplaying.start_time/end_time`；也可用现有 `v3/channels/{cid}/playbills` 拿 epoch ms。
  - 云听 `web/appProgram/listByDate`（现有节目单接口）→ 当天各节目 `startTime/endTime`（epoch ms），找覆盖 now 的一档。
- 决策（用户拍板）：直播进度区间用**节目单找当前节目**，两源统一用现有 `fetchPlaybill(channel, 今天0点)` 找覆盖 now 的节目，取其 `[startTime, endTime]`。找不到/失败则回退 24h（进度=当天已过时间/86400s）。
- 回放时长/进度来自播放器真实 `duration`/`currentPosition`（蜻蜓回放已由上一提交开启 CBR 估算出时长）。

## Requirements

### 通用
- R1 进度条配色用播放键同款红色 `YtmRed`（已填充部分红、轨道半透明白）。
- R2 回放：可拖动定位。直播：只读，不可拖动、不可聚焦。
- R3 时间格式：`当前/总`，例 `23:45/1:00:00`；<1h 显示 `mm:ss`，≥1h 显示 `h:mm:ss`，两侧各自独立判断。

### 回放拖动交互（TV 与手机一致）
- R4 单击方向键（TV）左/右：快退/快进 15 秒。
- R5 长按方向键：连续快退/快进（按键自动重复即连续 15s 累加）。
- R6 手机触摸：拖动进度条改变目标位置。
- R7 拖动/调整过程中**不立即 seek**，只更新预览位置并显示时间。
- R8 防抖：最后一次调整后 1 秒无新动作 → 关闭时间显示，并真正 `seekTo` 开始加载音频。
- R9 拖动时的时间显示：
  - TV：电台封面上方加遮罩，用**大字**显示 `当前/总`。
  - 手机：拖动点（thumb）显示为**胶囊**形状，胶囊内显示 `当前/总`。

### 位置
- R10 TV（竖排/横屏左侧面板 `horizontal=false`）：进度条置于**节目名（副标题）与播放键之间**。
- R11 手机（底部横排播放条 `horizontal=true`）：进度条置于**底部播放组件的顶部**（在现有 Row 之上）。

## Acceptance Criteria

- [ ] 回放时进度条显示真实 position/总时长，随播放推进；直播显示当前节目进度且每秒推进。
- [ ] 直播进度条不可聚焦/不可拖动；回放可聚焦（TV）并响应左右键 ±15s。
- [ ] TV 长按方向键连续快进/快退。
- [ ] 手机可触摸拖动，thumb 为胶囊显示 `当前/总`。
- [ ] 拖动中不 seek；停手 1 秒后关闭时间显示并开始加载（进入缓冲）。
- [ ] TV 拖动时封面上方大字显示 `当前/总`。
- [ ] 进度条位置：TV 在节目名与播放键之间；手机在底部播放条顶部。
- [ ] 配色为播放键红色。
- [ ] 直播拿不到节目单时回退 24h 进度不崩溃。

## Notes

- 直播 HLS 的 player position 无意义，直播进度只用「节目窗口 + 墙钟」计算，不读 player.currentPosition。
- 拖动预览与 seek 提交的防抖模式可参考现有 `SleepTimerSlider`（值变 1 秒后提交）。
